Warranty Void / Community

Build with us

Bring an idea, document an experiment, or help someone test a release.

The Discord workshop is invite-only. If you already know a member, ask the organizer privately for an invitation. You can contribute to public projects on GitHub.

From the first sketch

Bring a question or sketch to Idea Drop. Start a thread in Product Showcase with a photo, a prototype or something another member can test. Organizers choose what goes into Releases.

Connect your GitHub account

  1. Invited members can open My desk in Discord, or type !desk.
  2. Choose Connect GitHub and authorize your own account on GitHub.
  3. After an organizer assigns a project, choose My invitations and accept its invitation on GitHub. Watch gives read access. Build also lets you contribute.
  4. Open the project card for Review changes and Release notes. To find a room, choose Search projects and type its name.

Warranty Void on GitHub

Contribute or publish

Anyone can explore a public demo. Check the project’s licence before reusing its code or assets. You can open an issue or propose a change on GitHub. An organizer can invite collaborators to a private project individually.

Member Kanban

Invited collaborators use the signed-in board to track work. Releases appear in the public gallery when their project pages are published.
