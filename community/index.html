Build with us

Bring an idea, document an experiment, or help someone test a release.

The Discord workshop is invite-only. If you already know a member, ask the organizer privately for an invitation. You can contribute to public projects on GitHub.

From the first sketch

Use idea-drop for a question or sketch. Start one thread per prototype in build-logs. When others can try it, post the version, source or build files, licence, and instructions in releases.

Connect GitHub in Discord

  1. Open Discord’s User Settings → Connections.
  2. Select GitHub and authorize your own account on GitHub.
  3. Return to Warranty Void. Open the server menu and choose Linked Roles → GitHub Connected to claim the optional badge. Discord checks that you connected a GitHub account.
  4. For a private project, use /github-link in the server. The organizer assigns access per project. Accept the invitation on GitHub and use /my-projects to find your work.

Contribute or publish

Anyone can explore a public demo. Check the project’s licence before reusing its code or assets. You can open an issue or propose a change on GitHub. An organizer can invite collaborators to a private project individually.
