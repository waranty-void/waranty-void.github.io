From the first sketch

Use idea-drop for a question or sketch. Start one thread per prototype in build-logs. When others can try it, post the version, source or build files, licence, and instructions in releases.

Connect GitHub in Discord

  1. Open Discord’s User Settings → Connections.
  2. Select GitHub and authorize your own account on GitHub.
  3. Return to Warranty Void. Open the server menu and choose Linked Roles for available roles. You can also share your GitHub username with an organizer in bench chat if you want to join a project.

Contribute or publish

Anyone can explore a public demo. Check the project’s licence before reusing its code or assets. You can open an issue or propose a change on GitHub. An organizer can invite collaborators to a private project individually.

Member Kanban
